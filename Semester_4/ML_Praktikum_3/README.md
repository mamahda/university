## Deskripsi Tugas

Tugas ini menuntun mahasiswa untuk membandingkan beberapa pendekatan klasifikasi pada dataset citra sampah. Mahasiswa akan mengevaluasi model berbasis pembelajaran dalam (CNN dan ANN) serta model klasik (SVM) untuk melihat kelebihan dan kelemahan masing-masing.

## Tujuan Tugas

Tujuan dari tugas ini adalah:

- Mempelajari perbedaan antara model CNN, ANN, dan SVM dalam tugas klasifikasi citra.
- Mengimplementasikan CNN dari awal dan ANN untuk klasifikasi bernilai kontinu atau fitur terstruktur.
- Menggunakan SVM sebagai baseline klasik dan membandingkannya dengan model neural network.
- Mengevaluasi performa model menggunakan metrik yang tepat, seperti akurasi, precision, recall, dan F1-score.
- Menyajikan hasil perbandingan secara jelas dan memberikan rekomendasi model terbaik untuk dataset yang digunakan.

## Model yang Digunakan

Untuk tugas ini, model yang akan dipelajari dan dibandingkan adalah:

- **CNN from scratch**: Convolutional neural network yang dirancang untuk ekstraksi fitur visual dari gambar sampah.
- **ANN (Artificial Neural Network)**: Jaringan saraf multi-layer perceptron yang digunakan untuk membandingkan kinerja model dense dengan CNN.
- **SVM (Support Vector Machine)**: Model klasifikasi klasik yang bekerja baik pada data berdimensi tinggi dan dapat digunakan sebagai baseline.

## Dataset yang Digunakan

Dataset yang digunakan dapat diperoleh dari:

- https://www.kaggle.com/datasets/kaptenyasa/dataset-sampah
- https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
